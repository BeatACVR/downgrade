Windows Guide for Downgrading to 2.2081

You must own Geometry Dash on Steam for this guide to work.
It is recommended to save your account data to the cloud before proceeding with this guide.

Note: This guide assumes Geometry Dash is installed to the default Steam install location. If Geometry Dash is stored somewhere else, the paths you need to use will be different.

Click here to open the Steam console, or enter steam://open/console in the address bar of Edge or another browser.

Paste the following command into the console and press Enter:

  • download_depot 322170 322171 3816559102876907245

Wait for Steam to finish downloading the depot. If you get a permission error, try running Steam as administrator.

Open File Explorer and navigate to the following folder:

  • C:\Program Files (x86)\Steam\steamapps\content\app_322170\depot_322171

Copy everything inside this folder.

Go to the Geometry Dash installation directory:

  • C:\Program Files (x86)\Steam\steamapps\common\Geometry Dash

Paste the files and replace all existing files if prompted.

To prevent Steam from automatically updating Geometry Dash, go to:

  • C:\Program Files (x86)\Steam\steamapps

Right-click appmanifest_322170.acf, select Properties, enable the Read-only checkbox, click Apply, then press OK.

After Downgrading

You can now launch Geometry Dash through Steam and optionally install Geode v5.11.2.

If Geometry Dash receives a new update, you will need to launch it through GeometryDash.exe in the game's folder, or temporarily remove Read-only from appmanifest_322170.acf to update Geometry Dash then follow this guide to downgrade it again.

To get back to 2.2091

Remove Read-only from appmanifest_322170.acf, then right click Geometry Dash in Steam's sidebar. Click Properties, navigate to Installed Files, then click Verify integrity of game files.
